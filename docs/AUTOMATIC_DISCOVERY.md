# Automatic discovery

The customer desktop Scan is catalog evaluation, not general discovery. It
checks a closed set of exact macOS and Windows locations for Resolume Arena and
Serato DJ Pro. It does not enumerate applications, recurse through directories,
read candidate contents, inspect networks, or collect machine identity.

Exact paths remain transient in application memory. Signed-in submission sends
only opaque keys; the server independently allowlists each key and binds writes
to a manager-authorized organization and venue. An empty scan is stored so a
new absence supersedes older detections.
