# Account, billing, and administration boundary

Milestone 1 reuses existing organization, membership, role, and venue tenancy.
Direct-scan submission requires Manager, Administrator, or Owner membership for
the exact organization containing the exact venue. Read access remains scoped
to a membership in that organization.

Account invitations, billing, subscriptions, entitlements, customer lifecycle,
and production administration are not implemented by this milestone. The
personal-beta identity is bounded local Development scaffolding and cannot
create a customer or bypass tenant authorization.
